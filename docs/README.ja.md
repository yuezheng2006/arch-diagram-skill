# Motion Map

Animated relationship maps, architecture diagrams and illustrated explainers, maintained by yuezheng2006. Forked from bassnova42/arch-diagram-skill under MIT; see LICENSE and NOTICE.

The canonical guide is [README.md](../README.md). It documents the new `$motion-map` entrypoint, relationship types, five themes and offline exports.

```bash
git clone https://github.com/yuezheng2006/motion-map-skill.git
cd motion-map-skill
node bin/cli.mjs install
```

This fork is not published to npm. Existing installations of the upstream `arch-diagram` skill are not automatically removed.
